## Conventions learned with Claude

- All pages must use the full width of the viewport, not a partial width such as 50% or a constrained container.
- In Assistant, always scope the displayed data to the current project's connected datasources, never listing data from all projects.
- Make all tables server-side paginated, filterable, searchable, and sortable; default page size 15, options 5/15/25/50/100.
